# Source notes (read 2026-10-29)

**H-Net (Hwang, Wang & Gu 2025, arXiv 2507.07955v2).** Router p_t = ½(1 − cos(q_t, k_{t−1})), p_1 = 1, b_t = 1[p_t ≥ 0.5]. Ratio loss N/(N−1)((N−1)FG + (1−F)(1−G)); "We fixed α=0.03 in all experiments in this paper." EMA z̄_t = P_t ẑ_t + (1−P_t) z̄_{t−1}; c_t = p_t if b_t else 1−p_t; STE(c) = c + sg(1−c); residual Linear(x̂) "initialized close to 0"; a norm at the end of each encoder/decoder/main network; outer stages get higher learning rates (muP-style, App. C). Init of W_q/W_k not stated in the main text.

**Cartesia, From Tokens to Bytes I (28 Oct 2026).** H-Net vs BPE: 1.28x in-domain (same loss with 22% less compute); code in-distribution median 2.04x (1.49x Markdown to 2.40x Go); 10 unseen languages median 3.10x (2.19x Haskell to 5.37x Prolog). Unfamiliar words first split into several chunks, "as it encounters the same word multiple times, it progressively learns to group the word into fewer chunks." DNA: boundaries on codon borders, chunks 1–3 codons in coding regions; emerges late in training.

**Cartesia, From Tokens to Bytes II (28 Oct 2026).** Compute→loss and loss→downstream (loss-to-loss) efficiency. Same architecture and compression (4.57) for: entropy proxy (BLT-like, threshold on a separate byte model's next-byte entropy), frozen H-Net proxy boundaries, end-to-end H-Net. Validation BPB at 1e19 / 1e19.5 / 1e20 FLOPs: entropy 0.8160 / 0.7623 / 0.7138; H-Net proxy 0.8139 / 0.7504 / 0.7057; end-to-end 0.8001 / 0.7488 / 0.7027. Proxy FLOPs not counted (favours baselines). H-Net vs BLT-like multipliers: compute→val 1.40x, val→OLMES 1.32x, compute→OLMES 1.84x.

**HiLAM (Kim, Pinto & Kim, arXiv 2603.05815, 6 Mar 2026).** Two-stage H-Net over latent actions from a pretrained latent action model on actionless video; stage-2 chunks = latent skills. LIBERO-Long with 10% demos: 45% vs BAKU 23%; 50% demos 84% (≈ BAKU at 100%); 100% demos 94%. Boundaries evaluated only qualitatively (Fig. 4); no boundary metric against annotated subtasks. → RoboChunk's differences: real proprioceptive state + action input (no video), boundaries scored quantitatively against ground-truth phases and contact events, baselines inside the identical model, and the compression-as-novelty test.
