## 3. How the refractory window was chosen

The refractory router was added to the pre-registration (commit `1f1faa0`, 2026-10-29 14:08) as an exploratory variant, motivated by the pilot burst pattern (pilot v1: 58–67% of gaps between learned boundaries were 1 step). The window r = 3 was set once, by hand, with no sweep and no refractory pilot run; no other value was ever trained. The decision log records the motivation but no explicit reason for 3. It equals the ±3 tolerance of the primary F1, which matters: one-to-one matching counts extra boundaries within ±3 of one true boundary as false positives, and a 3-step refractory period removes exactly those. The ±1 numbers above are the check that the gain is not only that.

## 4. Burst locations on the real-robot test episodes

Burst = maximal run of boundaries with gaps < 3 steps. A burst is *at grasp / at release* if its span comes within ±3 steps of that gripper event (a long burst touching an event counts all its boundaries there); otherwise it is placed by position (start = within the first 5 steps; reach = before the first grasp; transport = between grasp and last release; retreat = after it). Event recall = share of gripper events with a boundary within ±3 steps.

## 5. Practical finding: a surprise-based rule marks gripper events

On Koch, the entropy rule (boundary where a small GRU's next-step surprise is above a threshold fitted for rate 1/12) puts 40% of its boundaries within ±3 steps (0.1 s) of a gripper open/close event, 10.3× the within-episode shuffle (p = 0.001, the smallest possible with 1,000 shuffles). It has a boundary within ±3 steps of 20 of the 20 test events, using 229 boundaries; the Fixed rule (297 boundaries) reaches 12. The learned router reaches 1.77× on the same episodes.

It does **not** replicate at that strength on SO-100: 1.77× chance (p = 0.001), event recall 0.75. There the threshold, fitted on only 5 validation episodes, gave far too many boundaries (test compression 4.59 for a target of 12), and 64% of them sit in bursts at the release.

Caveats: one proxy model per dataset, so the three entropy "seeds" are identical; 10 and 5 test episodes; the threshold is fitted on very few validation episodes. As a practical tool — flagging grasp and release moments in teleoperation logs without labels — the result is promising on one dataset, not established.
