# RoboChunk

A small **pre-registered** study of H-Net-style dynamic chunking on robot trajectories, run on one Mac mini.

- **Part A.** Does a learned H-Net router, trained only to predict the next step of a robot trajectory, place its chunk
  boundaries at real motion-phase changes (simulation, with ground-truth phases) and at gripper events (real teleoperation)?
  Does learned chunking predict better than fixed chunking at matched compression?
- **Part B.** Can the same model's compression (bits per step on a candidate dataset vs held-out reference data) predict
  how much that dataset improves a behaviour-cloning policy?

**Status (2026-10-31): complete.** Full results in **[REPORT.md](REPORT.md)** (every number generated by
`scripts/make_report.py` from the files in `runs/`). Hypotheses, metrics and thresholds were committed before any main
result (`PREREGISTRATION.md`, tags `prereg`, `prereg-amend1`; `PREREGISTRATION_v2.md`, tag `prereg-v2`).

## Reproduce

Python 3.12 with `requirements.txt` (MuJoCo 3.3.7, gymnasium-robotics 1.4.2, PyTorch). CPU only.

```bash
python scripts/make_sim_data.py                   # simulated splits (FetchPickAndPlace-v4, scripted expert)
python scripts/make_partb_data.py                 # Part B reference and candidate datasets
python scripts/make_configs.py && scripts/run_main.sh   # all pre-registered sequence-model runs (≈ 1 day on a Mac mini)
PYTHONPATH=. python scripts/analyze.py all        # H1–H4 and exploratory analyses
PYTHONPATH=. python scripts/analyze_v2.py         # v2 confirmatory test (after JOBS=2 scripts/run.sh configs/v2/*.yaml)
PYTHONPATH=. python scripts/make_figures.py && python scripts/make_report.py
```

Checkpoints of the simulated-data and Part B models: [huggingface.co/PAOP123/robochunk](https://huggingface.co/PAOP123/robochunk).
Simulated data and result files: [huggingface.co/datasets/PAOP123/robochunk-sim](https://huggingface.co/datasets/PAOP123/robochunk-sim).

Before committing, run
`sh scripts/install_hooks.sh` once: the hooks block e-mail addresses, tokens and data files.

Real datasets are read from Hugging Face (`lerobot/svla_so100_pickplace`, `lerobot/koch_pick_place_1_lego`, and for v2
`lerobot/svla_so101_pickplace`) at the revisions pinned in `DECISIONS.md` and `PREREGISTRATION_v2.md`; only their parquet
tables and metadata are downloaded, and they are not redistributed here.
